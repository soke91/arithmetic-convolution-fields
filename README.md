# Arithmetic convolution fields

Purpose: public index of self-contained reproduction packets, one directory per paper.

Not in this repository export: private working history, research queues, or superseded claims.

Each `P*-*/` directory contains a standalone manuscript, compiled PDF, exact
scripts and saved results, a machine-readable `PACKET.json`, and formalization
where one exists. Packet bytes are generated and checked from the working
repository; no human selects files during export.

Run a script from its paper directory after installing `requirements.txt`.
Some scripts deliberately exit nonzero when their preregistered rule is refuted;
read the saved output for the verdict.

The working repository records history and retractions that this public
reproduction projection does not expose. No paper's main theorem should be
inferred to be machine-checked merely because a Lean directory is present.
